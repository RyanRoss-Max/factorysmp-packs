# factorysmp-packs

Resource packs publicos do FactorySMP (Java + Bedrock).

## Java (Paper)

- Ficheiro: `FactorySMP-Java-1.21.11.zip`
- SHA1: `4028678abed55ca0b146ef5c81d2763be68c6659`
- URL: https://raw.githubusercontent.com/RyanRoss-Max/factorysmp-packs/main/FactorySMP-Java-1.21.11.zip

Inclui icones custom (`factorysmp:item/*`) e retextura das maquinas no chao (blast furnace, smoker, respawn anchor, cauldron, anvil).

## Bedrock (Geyser / PocketMine)

- Ficheiro: `FactorySMP-Bedrock.mcpack` (v1.2.0)
- URL: https://raw.githubusercontent.com/RyanRoss-Max/factorysmp-packs/main/FactorySMP-Bedrock.mcpack

Icones de itens + overrides de blocos vanilla para maquinas industriais.

## Atualizar no servidor

Depois de push neste repo, em `java-crossplay`:

```powershell
tools\Update-ServerResourcePack.ps1
```

Reinicie o Paper (`start-java.cmd`).
